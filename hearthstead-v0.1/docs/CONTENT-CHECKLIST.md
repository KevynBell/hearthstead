# Hearthstead v0.1 — Public launch checklist

This site is a **working internal prototype**, not a finished public membership platform.

## Content and identity

- [ ] Network gives feedback on the final community name.
- [ ] Check relevant domains, company/organization names, and trademarks before committing.
- [ ] Verify every personal bio, skill, and project claim with its owner.
- [ ] Obtain documented consent from any new workshop owner for public display.
- [ ] Replace generic SVGs with approved work, images, or portraits when appropriate.
- [ ] Identify demo projects clearly; never present fictional clients as real customers.
- [ ] Review copy for clarity and any unintentional promises of access or outcomes.

## Site readiness

- [ ] Test keyboard navigation and screen reader landmarks.
- [ ] Check responsive behavior from 320px up through desktop.
- [ ] Review contrast, focus states, and images in both color themes.
- [ ] Test forms and filters without JavaScript; provide a sensible fallback or document limitations.
- [ ] Add custom 404 page and public contact details before real deployment.
- [ ] Check browser support and performance / Core Web Vitals.
- [ ] Configure a domain, DNS, and managed HTTPS at a hosting provider.
- [ ] Decide whether the repo will be public, including ownership and licensing.

## Community and organizational safeguards

- [ ] Draft member eligibility, content standards, and review/appeal process.
- [ ] Plan consent, data ownership, export, and profile removal procedures.
- [ ] Establish privacy policy and accessible contact channels.
- [ ] Review nonprofit/legal pathways with qualified counsel and advisors.
- [ ] Decide how funding, transparency, and governance will work before accepting funds.
- [ ] Avoid promising free lifetime services before assessing sustainable operations.
- [ ] Evaluate abuse prevention without imposing unnecessary financial barriers.
